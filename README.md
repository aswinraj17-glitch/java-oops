# Java OOP Scenario Practice

This repository contains simple Java programs based on the OOP scenario-based interview questions developed in this chat.

## Topics
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Method Overriding
- Real-world class design

## Scenarios
Bank Account, ATM, Cab Booking, Employee Salary, Library, Parking Lot, Food Ordering, Hotel Booking, Payment Gateway, Notification System, Smart Home, Online Exam, Cricket Team, CampusMart and more.

Each scenario is kept as a separate Java file so it can be compiled and practiced independently.
